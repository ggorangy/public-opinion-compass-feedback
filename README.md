# 여론 나침반 오류·정정 제보

여론 나침반 서비스의 오류, 인물·출처 정보 정정, 접근성 문제와 이용 의견을 접수합니다.

## 제보 전에 확인해 주세요

- 이 저장소와 이슈는 **공개**됩니다. 이름, 전화번호, 이메일, 계정 정보, 비공개 대화 등 개인정보나 민감정보를 적지 마세요.
- 정정 요청에는 확인 가능한 공개 출처 URL과 문제가 있는 화면·문구를 적어 주세요. 제보 내용은 검토 후 반영 여부를 결정합니다.
- 이슈 등록은 수정·답변 시점이나 서비스 반영을 보장하지 않습니다.
- 이 저장소는 오류·정정 접수 전용이며 서비스의 소스 코드 저장소가 아닙니다.
